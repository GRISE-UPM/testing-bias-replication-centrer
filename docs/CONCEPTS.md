# Concepts

- <a id="c-organizer"></a>**Organizer**: UPM and ESPE researchers who launch and manage the research project.

- <a id="c-researcher"></a>**Researcher**: Any visitor of the portal. They can only access  the landing page.

- <a id="c-interested-researcher"></a>**Interested researcher**: Any authenticated user of the portal (see [nfr-authentication](https://github.com/GRISE-UPM/testing-bias-replication-centrer/blob/main/docs/NON-FUNCTIONAL-REQUIREMENTS.md#nfr-authentication)). We assume that they are researchers, but they may also be simply casual visitors. They shall not be able to access detailed data or artifacts: the portal does not show them the location of the replication repositories (see [c-replication-repository](https://github.com/GRISE-UPM/testing-bias-replication-centrer/blob/main/docs/CONCEPTS.md#c-replication-repository)).

- <a id="c-participant-researcher"></a>**Participant researchers**: Any external researcher that joins the project. Participation requests shall be validated (see [nfr-participation](https://github.com/GRISE-UPM/testing-bias-replication-centrer/blob/main/docs/NON-FUNCTIONAL-REQUIREMENTS.md#nfr-participation)).

- <a id="c-replication-material"></a>**Replication materials**: Documents, code and scripts needed to conduct or analyze a replication.

- <a id="c-replication-result"></a>**Replication result**: Documents, code and data generated by a participant researcher during a replication.

- <a id="c-experimental-subject"></a>**Experimental subject**: Person who takes part in a replication. Subjects submit their work through a pull request from a fork of the replication repository (see [c-replication-repository](https://github.com/GRISE-UPM/testing-bias-replication-centrer/blob/main/docs/CONCEPTS.md#c-replication-repository)).

- <a id="c-replication-repository"></a>**Replication repository**: Git repository, created from a template, that contains the replication materials (see [c-replication-material](https://github.com/GRISE-UPM/testing-bias-replication-centrer/blob/main/docs/CONCEPTS.md#c-replication-material)) and the work of the experimental subjects (see [c-experimental-subject](https://github.com/GRISE-UPM/testing-bias-replication-centrer/blob/main/docs/CONCEPTS.md#c-experimental-subject)) of one replication. It is hosted either in the organizers' GitHub account or in an account chosen by the participant researcher (see [c-participant-researcher](https://github.com/GRISE-UPM/testing-bias-replication-centrer/blob/main/docs/CONCEPTS.md#c-participant-researcher)). It is public while the experiment is conducted. The portal shows its location only to participant researchers.

- <a id="c-meter"></a>**Meter**: Tool that analyzes the work of the experimental subjects and produces the standardized result files of a replication (see [c-replication-result](https://github.com/GRISE-UPM/testing-bias-replication-centrer/blob/main/docs/CONCEPTS.md#c-replication-result)).

- <a id="c-project-repository"></a>**Project repository**: Private GitHub repository of the organizers that stores all replication results and consolidated data. It is version-controlled (see [nfr-recovery](https://github.com/GRISE-UPM/testing-bias-replication-centrer/blob/main/docs/NON-FUNCTIONAL-REQUIREMENTS.md#nfr-recovery)) and encrypted (see [nfr-encryption](https://github.com/GRISE-UPM/testing-bias-replication-centrer/blob/main/docs/NON-FUNCTIONAL-REQUIREMENTS.md#nfr-encryption)) while private.

- <a id="c-consolidated-data"></a>**Consolidated data**: Data derived from the replication results and stored in the project repository (see [c-project-repository](https://github.com/GRISE-UPM/testing-bias-replication-centrer/blob/main/docs/CONCEPTS.md#c-project-repository)). There are two levels: *per-replication* consolidated data, which contains only the data of one replication, and *global* consolidated data, which merges all replications.

- <a id="c-replication-record"></a>**Replication record**: Descriptive information that participant researchers provide about a replication: planned dates and location, demographic data, drop-outs and links to the papers derived from it.

- <a id="c-clean-repository"></a>**Clean repository**: Newly created repository with no history and no links to forks, whose content is anonymized (see [nfr-anonymization](https://github.com/GRISE-UPM/testing-bias-replication-centrer/blob/main/docs/NON-FUNCTIONAL-REQUIREMENTS.md#nfr-anonymization)). It is used to close a replication repository managed by the portal and to publish the project repository.

- <a id="c-draft-article"></a>**Draft article**: RTeX report of one individual replication. It includes the experimental protocol (a web appendix identical for all replications) and the analysis derived from the meter (see [c-meter](https://github.com/GRISE-UPM/testing-bias-replication-centrer/blob/main/docs/CONCEPTS.md#c-meter)). It uses only per-replication consolidated data (see [nfr-data-isolation](https://github.com/GRISE-UPM/testing-bias-replication-centrer/blob/main/docs/NON-FUNCTIONAL-REQUIREMENTS.md#nfr-data-isolation)). Execution, demographics, drop-outs and interpretation are written by the authors.

- <a id="c-final-paper"></a>**Final paper**: Paper of the whole project. It references the individual papers and the global data, and includes the meta-analysis and the meta-regression.
